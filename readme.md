# QSpiders Training Projects

This repository contains all the projects, assignments, and practice programs that I developed during my training at **QSpiders**.

The repository includes work on topics such as:

- Core Java
- Advanced Java
- JDBC
- Hibernate
- Servlets
- Spring IOC
- Spring MVC
- Spring Boot
- Spring Data JPA
- REST APIs
- Multithreading
- Practice Programs
- Other training exercises and mini projects

The purpose of this repository is to document my learning journey and maintain all the code written and practiced throughout the training.

Basic `MAVEN` commands:
```
mvn clean
mvn compile
mvn test
mvn package
mvn install
mvn spring-boot:run
```
